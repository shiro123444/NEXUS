## 签到功能测试

### 用户端（8080）
1. 使用任意用户登录
2. 在Dashboard页面可以看到「每日签到」卡片
3. 点击「✨ 立即签到」按钮
4. 查看获得的tokens数量
5. 查看签到历史日历

### 管理端（8081）
1. 使用超级管理员登录
2. 点击「签到配置」标签页
3. 修改最小/最大奖励范围
4. 查看签到统计数据

## 签到配置
- 默认最小奖励：1000 tokens
- 默认最大奖励：5000 tokens
- 可在8081管理后台修改

## 启动命令
```bash
# 启动8080用户门户
python3 -m kiro_proxy.portal.user_app

# 启动8081管理后台
python3 -m kiro_proxy.main 8081

# 或者使用统一启动脚本
python3 run.py
```
